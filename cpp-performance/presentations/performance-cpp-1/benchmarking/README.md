# Дополнительные бенчмарки

Здесь находятся исполняемые версии трёх последних сравнений презентации:
передача маленькой структуры по значению и по ссылке, ручная предвыборка и
пакетное обновление атомарного счётчика.

`cases.cpp` и `benchmark.cpp` нужно компилировать как отдельные единицы трансляции
без LTO. Каждый запуск прогревает обе реализации, чередует их порядок в 11 сериях,
печатает медиану в CSV и завершает работу с ошибкой при неверном результате.

~~~sh
g++ -std=c++17 -O3 -pthread cases.cpp benchmark.cpp -o benchmark-gcc
clang++ -std=c++17 -O3 -pthread cases.cpp benchmark.cpp -o benchmark-clang

./benchmark-gcc parameters
./benchmark-gcc prefetch
./benchmark-gcc atomic
~~~

Числа на слайдах получены на AMD Ryzen 5 4600H в WSL2 с GCC 13.3 и Clang 18.1.
Потоки не закреплялись за ядрами, частота процессора и фоновые процессы не
контролировались. `__builtin_prefetch` — расширение GCC и Clang, а не C++17.

Пакетное обновление атомарного счётчика эквивалентно по конечному результату
только тогда, когда промежуточные значения не наблюдаются другими потоками.
